# Calm Coach: Meltdown Moments

A tiny, very pink browser game designed for a mom who wants to practice regulating her own emotions during bedtime, end-of-day, and kid-meltdown moments.

The game is intentionally short, warm, and replayable, with each five-round practice pulling from a larger set of varied scenarios. It is not about “winning” against the child; it is about building the parent’s pause muscle before responding.

## Core learning loop

The player practices the **S.C.A.N. Calm** routine:

1. **Stop** — pause before reacting.
2. **Check** — notice body cues and emotional intensity.
3. **Anchor** — take one slow breath or grounding action.
4. **Name** — name the child’s likely need and choose a calm response.

Each round presents a kid-meltdown, bedtime, or end-of-day scenario. The player chooses one response. Regulating choices earn calm points and lower the storm meter. Reactive choices raise the storm meter but offer a repair prompt so the game stays encouraging.

## Emotional safety principles

* The child is never framed as bad or manipulative.
* The mom is never shamed for getting activated.
* Mistakes become repair practice.
* The game reinforces co-regulation: calm is something the adult lends to the child.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.
